Drafted answers meant to be posted externally, MR review replies, Jira comments, Figma comments, must stay short, concise, kind, and never use an em dash.

**Why:** user repeatedly asked to shorten a drafted [[mr-comment-fix]] reply (full explanation, then 3 lines, then 1-2 lines), then said this applies whenever drafting these external answers. User separately added the no-em-dash rule.

**How to apply:** any drafted text meant for an external reviewer or stakeholder. Default to 1-3 sentences, plain and kind, no over-explaining, no em dashes (use a comma, period, or "and"/"but"), expand only if asked. Does not apply to explanations addressed to the user, which can stay detailed.
